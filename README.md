# ANUARUS — Sistema Clínico de Fuerza y Nutrición
**Entrenador y Nutriólogo: Diego Rodea**

Aplicación web minimalista en blanco y negro diseñada para el control antropométrico, cálculo de **FFMI**, **% de Grasa Corporal**, diagnóstico de **puntos débiles**, progresión semanal de cargas en **6 ejercicios básicos** (en kilos o libras), análisis biomecánico de **videos** y exportación de **Informes PDF para envío por WhatsApp**.

## Cómo alojar en GitHub Pages (Gratis)
1. Crea un nuevo repositorio en [GitHub](https://github.com/new) (por ejemplo, `anuarus`).
2. Sube todos los archivos de esta carpeta a tu repositorio:
   - `index.html`
   - `styles.css`
   - `app.js`
   - `illustrations.js`
   - `logo-data.js`
   - `assets/logo.jpg`
3. Ve a la pestaña **Settings** de tu repositorio → menú lateral **Pages**.
4. En **Build and deployment → Branch**, selecciona `main` y carpeta `/ (root)` y haz clic en **Save**.
5. En unos segundos tu aplicación estará disponible en `https://<tu-usuario>.github.io/<tu-repositorio>/`.
